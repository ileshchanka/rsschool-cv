# rsschool-cv

CV built for the RS School CV task: a Markdown version and a semantic HTML/CSS page,
plain CSS, no frameworks.

Deployed versions:

- Markdown CV: [https://ileshchanka.github.io/rsschool-cv/cv](https://ileshchanka.github.io/rsschool-cv/cv)
- HTML CV: [https://ileshchanka.github.io/rsschool-cv/](https://ileshchanka.github.io/rsschool-cv/)

## HTML version

`index.html` and `style.css` hold the laid out CV page:

- semantic markup (`header`, `nav`, `main`, `section`, `article`, `footer`), one `h1`;
- valid according to the [W3C Markup Validator](https://validator.w3.org/);
- content centred in a fixed-width container, responsive down to mobile widths;
- navigation, contacts and skills marked up as lists;
- footer with a link to GitHub, the year and the RS School logo linking to the course.
